# 分阶段开发计划

每阶段均以“实现 → 自动测试 → 实际运行 → 修复 → 阶段记录”为完成门槛。

1. **工程骨架（本阶段）**：包结构、配置、日志、SQLite 初始化、核心接口、最小 GUI、测试入口。
2. **规则引擎**：完整棋子规则、合法着、将军/应将/将死、局面不可变模型与规则专项测试。
3. **棋盘 GUI**：点击/拖动、提示、高亮、动画、翻转、缩放和 DPI 实测。
4. **Pikafish**：UCI 后台服务、自动发现、NNUE、MultiPV、取消/超时/崩溃恢复与假引擎集成测试。
5. **FEN 与棋谱**：双向记谱、歧义消解、导入导出、数据库浏览。
6. **沙盘**：不可破坏原谱的变化树、分支比较、节点分析。
7. **AI API**：OpenAI-compatible Provider、凭据存储、连接测试、重试和缓存。
8. **AI 导师**：分任务 PromptBuilder、证据边界、渐进提示、结构化箭头/高亮。
9. **训练系统**：许可可追溯的残局导入、猜棋、学习事件和报告。
10. **完整测试与交付**：整盘复盘、分辨率和高 DPI 检查、PyInstaller、依赖许可证、README。

Phase 2 的验收重点是规则正确性，不提前用 GUI 行为掩盖规则缺陷。
